# 为什么用 Bolloon

> 写给 16–30 岁、研究型、跨学科、有品味、为大模型付过费的人。

## 一、你是谁

你大概率是这样的人：

- **16–30 岁**，正在读本科、研究生，或者刚毕业不久。
- **研究型人格**。你不是来"玩 AI"的，你是真的在用 AI 做东西 —— 写论文、做课题、做毕业设计、做副业项目。
- **跨学科**。你可能主修物理、数学、神经科学、脑科学、工业工程、商科，但你同时会看漫剧、追番、做内容、玩乐队、搞创作。学科之间在你脑子里不是分开的，是同一条河流。
- **懂 AI 智能体**。你用过 ChatGPT、Claude、Gemini、Cursor、Devin、Manus、Coze、Dify…… 你不是"听过 AI"，你是"用过 AI 干活"。
- **为模型付过费**。你给 ChatGPT Plus、Claude Pro、Cursor Pro、API key 至少其中之一充过钱。免费版你已经不满足了。
- **有品味**。你看一眼某个 AI 产品就知道它是"工程感"还是"产品感"。你能区分"做了"和"做对了"。
- **有判断力**。你知道什么是 hype，什么是真的。你不会被"DEMO 视频"打动，你只看"我用了一周还愿意继续开"的产品。
- **有创新力和想象力**。你不只是想"用 AI 提高效率"，你想"用 AI 做现在还不存在的东西"。
- **想找同类**。你身边能聊懂这些事的人很少。你想找到同样的人 —— 一起做项目、一起吐槽、一起写点东西。

如果上面有 6 条以上戳中你，这篇文档就是写给你的。

## 二、你现在用 AI 的痛点

你大概率遇到过这些问题：

1. **每次开新对话，AI 就把之前的事忘了**。你上周教它的偏好、你的写作风格、你项目的背景、本周它在另一台机器上做的草稿 —— 全没了。你在重复劳动。
2. **你换一台设备，AI 就变成陌生人**。家里 Mac、出门 iPad、公司 Windows、手机 iPhone —— 每个终端都是一个孤岛。
3. **AI 给你的内容越来越"像 AI"**。句式工整、四平八稳、零观点、零锐度。你一眼能看出是 AI 写的，你想让它像你写。
4. **AI 不会主动积累你的判断力**。你纠正过它 100 次，它下次还是犯同样的错。它学到了你的 prompt，没学到你的**人**。
5. **你试过自己搭工作流**，但每次搭完又散 —— 因为 LLM 升级一次 API 变一次、模型换一次 prompt 全废、记忆系统自己写成本太高。
6. **你想找同类协作，但所有平台都把你们当"用户"而不是"同行"**。Discord 上有人聊但没人做，GitHub 上有人做但都藏着，X 上有人吹但都不写代码。
7. **你做的项目（漫剧、脑科学建模、数学证明、商业分析）需要长期沉淀**。今天想到的点子，下周再用已经断片。

如果你中过其中 3 条以上，你已经踩过"通用 AI 工具的天花板"。

## 三、Bolloon 是给谁做的

Bolloon 不是给"所有人"做的 AI 工具。

Bolloon 是给**有研究能力 + 有跨学科兴趣 + 有判断力 + 愿意为模型付费 + 正在做具体项目**的人做的。

具体一点：

- 你是一个数学系本科生，同时在做脑科学方面的独立研究，想让 AI 帮你把两个领域串起来。
- 你是一个商科研究生，同时在画漫剧分镜，想让 AI 既能帮你做 case study，又能帮你写剧本梗概。
- 你是一个工业设计师 + 业余神经科学爱好者，正在做一个"脑机接口 + 漫剧叙事"的项目，想找一个能跨会话积累你所有资料的 AI。
- 你是一个物理 PhD，平时写点技术博客，想让 AI 学会你"先讲直觉再讲公式"的风格。
- 你是一个 AI Agent 重度用户，自己已经在写 skill / 写 prompt / 调 API，但你想找一个"不锁死在某个 provider、能在多台机器同步、能把我的判断力沉淀下来"的底座。

如果你是上面任何一种，Bolloon 就是为你做的。

## 四、Bolloon 不解决的问题（先说清楚）

诚实比夸大重要。Bolloon **目前不能**解决：

- ❌ 替代你真正做研究、写论文、做实验。AI 是工具，**你才是研究者**。
- ❌ 给你"全自动"的承诺。它需要你喂资料、调 prompt、写 skill、纠错。这是一个**放大器**，不是替代品。
- ❌ 让一个完全没有基础的人"秒变专家"。如果你不想花时间读文档、调参数、养 skill，Bolloon 不适合你。

## 五、Bolloon 解决的问题（核心六条）

1. **AI 不再每次从零开始**。Bolloon 把你和它的对话、你的判断、你的偏好、你的项目背景 —— 沉淀成本机上的"记忆"。换设备、同步账号、不丢任何东西。
2. **判断力会复利**。你纠正它一次，下次它不会犯同样的错。你给它一个观点，它会记住你"为什么这么想"。**它学的不是 prompt，是你的人**。
3. **多模型可切换，不被锁死**。你用 OpenAI、用 Anthropic、用开源模型 —— Bolloon 不替你选。你觉得 GPT 适合代码、Claude 适合写作，自己换就行。
4. **本地优先，数据在你手里**。你的对话、你的 skill、你的 session 全部在你本机的 `~/.bolloon/` 下。不上传、不被训练、不依赖中心服务器。**你是数据的主人**。
5. **跨设备无缝切换**。Mac、iPad、Windows、iPhone、Linux —— 同一个 bolloon 实例跟着你走。回家打开 Mac 继续手机上的对话，去图书馆打开 iPad 继续家里的项目。
6. **可以找同类协作**。Bolloon 是 P2P 网络，你的 bolloon 实例可以直接和另一个人的 bolloon 实例对话 —— 不需要平台撮合、不需要经过中心服务器。**你和你的同行直接连**。

## 七、为什么是现在

你可能在想："这种东西 ChatGPT 不久也会做？"

答案是：**不会。**

- ChatGPT 是为"最大化 DAU"设计的。它希望你每天开 20 次新会话、每次都重新开始。它的商业模式**和"沉淀你的判断力"是冲突的**。
- Notion AI、Obsidian AI、Cursor 都在做"局部记忆"，但它们的记忆**只服务于自己的产品边界**（笔记、代码、写作），无法跨场景沉淀你的整个人。
- 真要做"沉淀你的判断力"，必须**本地优先 + 用户拥有数据 + 不被中心化产品绑架**。这是 ChatGPT 永远不会做的事。

这是 Bolloon 存在的全部理由：**做一个 ChatGPT 永远不会替你做的东西。**

2. **跑一次消融实验** —— 看 [docs/ablation/](../ablation/) 了解它在真实场景下能做什么、不能做什么。

4. **找另一个用 Bolloon 的人连一下** —— 体验 P2P 协作。不需要服务器、不需要账号、不需要中间人。
