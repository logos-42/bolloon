# CLI 启动面与面板几何

**口径 (leo 2026-09-27)**: 敲完 `bolloon --cli` **直接就该看到面板**。启动期那一坨
(初始化状态 / 就绪度 / 已完成阶段 / 配置来源 / 已存输入 / 缺什么 / 下一步 / 启动面板框 / Onboard 模式)
**默认不上屏**, 但 `--verbose` / `BOLLOON_VERBOSE=1` 下**一字不少地回来**;
**失败 / 需人介入** (缺 key、连通性实测失败、初始化中断) 折成 `/!\` 开头的提示行, **不许吞**。
面板要**能选能复制** (不许 alt-screen / 频繁清屏打断终端选择), 固定行**几何不抖**,
上滚能**暂停跟随**、PgDn/End 回底。

## 1. 修前 → 修后 (真 pty 抓包)

| 量 | 修前等价 (`BOLLOON_STARTUP_PREAMBLE=1`) | 默认 (`bolloon --cli`) | `--verbose` |
|---|---|---|---|
| 第一帧**之前**的屏上输出 | 19 行前言 | **0 行** | 58 行 (19 行前言 + log-gate 启动日志全量) |

- 判据不是手写清单, 而是**同一轮里再跑一遍老路径**: 老路径打出来的**每一条** verbose 都得有
  (B1 逐条 9/9, B2/B3 去掉带 tmp 路径的 `[log-gate]` 行后**逐字比 19/19 找到, 缺 0 行**)。
- 默认模式的 0 行是**真 pty 第一帧之前**量出来的 (`pre_bytes=0`), 不是"看日志觉得没有"。
- ⚠ 行数随环境抖 (那一坨里 `已存输入:` 只在 setup store 真有存过输入时才打) —— 所以判据一律
  **同轮同一构建**互比, 不写死 18/19 这种数; 上表是 2026-09-27 收尾轮复测的值。

## 2. 实现 (判据 / 落屏 / 不许吞)

- `src/cli/startup-notice.ts` — 启动期"续跑前言"**唯一判据**: `startupPreambleVisible(env, args)`
  (默认 false; `--verbose` / `BOLLOON_VERBOSE=1` / `BOLLOON_STARTUP_PREAMBLE=1` 为真) +
  `noticeLine()`(闸门) + `flushStartupNotices()`(把攒着的一次性落屏)。
- `src/cli-entry.ts` — 面板前那一段走闸门; 落屏与否**只影响"什么时候打", 不影响"打什么"**。
- `src/cli/setup-wizard.ts` — `flushQuiet()` 改**双缓冲落屏**: 要人当场回答前, 先把向导自己攒的
  + `startup-notice` 攒的**一起**落屏, 否则等于"把失败原因吞了"(两处调用幂等)。
- **失败不吞**: 告警行折成 `/!\` 前缀并进面板 (`⚠ 未就绪 (门禁: setup): 缺身份 …` 真在面板里)。
  ⚠ **转义坑**: 源码字面量里必须写 `\\ ` —— 少一个反斜杠 JS 会把 `\ ` 吃成空格, 屏上变
  `/! `, 验收门 A4 按 `/!\` 判 (**真踩过一次**, 注释里留了防复发说明)。
- **启动期进度 / 降级行的唯一出路 `bootNotice()`** (`src/index.ts`, 2026-09-27 收尾轮):
  面板之前那些 `s.info` / `s.warn` (模型装配 / Kubo / `发布 DID → IPFS` / P2P / iroh / bootstrap)
  不再直接 `console.log` —— 默认口径下**带人信号的折进面板告警通道** (面板没画就
  `pushStartupAlert` 登记, 面板已画就当场 `appendLine` 追加, 晚到的失败也不许烂在内存里),
  **不带信号的只落 `startup.log`**; `--verbose` / `BOLLOON_STARTUP_PREAMBLE=1` / 非交互 / web
  逐字照旧。判据复用 `log-gate.carriesHumanSignal()` (**只有一处**)。
  为什么必须这么收口: 那条 `⚠ [2/5] 发布 DID → IPFS` 是**真降级** (本机无可用 IPFS),
  它既是"启动前多出来的 1 行", 又是"失败不许吞"。只顾一头都是错的 ——
  A1 (`面板前 0 行`) + A7 (`真发生过的降级必须能在面板里逐字定位`) 成对才叫收口。

## 3. 面板几何不抖 (真 pty 逐帧量)

固定行 (状态栏 / 输入栏 / 活动行) 都显式 `height={N}` + `overflow="hidden"` + `width={budget.cols}`:
只给 width 时子文本换行会**撑高 Box**, 顶掉下行 → Ink 从顶切行 → 整屏行号漂。

| 断言 | 结果 (60 列窄屏, 逐字符键入 22 字含中文) |
|---|---|
| D1 每帧总行数 == 终端高 | 19 帧全部 **24** |
| D2 输入行行号恒定 | 42 帧全部 **22** |
| D2b 固定栏行号恒定 | 三条整宽分隔线 `20,22,24` · 状态栏 `20` |
| D3 打字引起的重绘最小 | 18 对相邻帧里 **16 对**差异只在动态行 (其余 2 对是启动期承重帧) |
| D4 长输入按宽度裁剪 | 末帧输入行 `❯ nvidia-provider-测试`, 帧高不涨 |

## 4. 跟随可暂停 (探针 + 帧双证据)

面板内置 `BOLLOON_TUI_PROBE=<file>` 探针 (每帧一条 JSON: `stick/top/maxTop/history/msgH/inputLine`)。

- 上滚 → 探针 `stick=false && top>0` (**真暂停**, 不是"被强拉回底部"); 屏上出现
  `已暂停跟随 · PgDn/End 回到底部 (↑N 行 · Ctrl+U/D 翻页 · Home 到顶)`。
- `Ctrl+E`/End → 探针 `stick=true && top==maxTop` (**恢复跟随**)。
- 面板高度 == 终端真实高度 (`rows`), 历史区 == `高度 − 面板(状态栏+活动行+输入栏+分隔线)`。

## 5. 可复制 (`/copy` 真落剪贴板)

- `src/cli/clipboard.ts` 提供 `clipboardWrite()`; `BOLLOON_CLIPBOARD_CMD` 可换成脚本 (门就用它做 **stub**)。
- 判定: **stub 真收到字节** + 面板**自报字符数**与 stub **实收字符数逐位相等**
  (C1/C2 均为 `90 字符`; 内容不入报告, 只报计数)。
- 复制路径下**运行期 `2J` 清屏帧数 = 0**, 且面板**不用 alt-screen** ⇒ 终端自己的选择/复制不被抢走。

## 6. 会话内 `/model` 的可见范围 (与 CLI 子命令**共用同一套选择器**)

真终端里 `/model` 走 `modelTtyIO()` + `runModelCommand` = **与 `bolloon model` 同一个
`tui-select` 全屏选择器** (`src/index.ts` 里 `runModelCommand(modelArg)` / `modelTtyIO()` /
`tui-select.js` 三处源码级断言, H4)。非终端才退回 Ink 小弹窗兜底。

真 pty (会话里敲 `/model` → 选择器) 实测:

| 断言 | 结果 |
|---|---|
| H1 家数 == 门**自己从盘上真算** | 屏上 `共 231 家登记` == `buildProviderSummaries()` = **231** |
| H2a 折叠态连续 ↓ 走到行集末尾 | 采 314 帧, `第 12/12` (**i == N**, 不卡窗口边界) |
| H2b **展开全部折叠组**后连续 ↓ 走到候选末尾 | 采 1427 帧, `第 237/237` (231 家 + 分组标题 + Cancel) |
| H3 单帧总行数 | 分布 `11,12,13,14,15` (固定视窗 12 行 + 头/状态/上下指示) ≤ 终端高 30 |

⚠ **如实留下**: 默认态**折叠**的分组, 其成员**不在 ↓ 的行集里** (`N=12`) —— 这是设计口径
("折叠 = 不画成员行, 但标题照写家数; 搜索命中平铺", 见 `model-selector-p2.md §9`), 不是漏项:
到成员的两条路是 `空格/→` 展开(本条 H2b 走的路) 或**直接打字筛选**(命中平铺, 折叠挡不住)。

## 8. 夹具踩过的坑 (`scripts/pty-run.py`, 门承重件)

1. **尺寸要在 fork 之前设**: 先开窗再 `TIOCSWINSZ` 会让子进程在 `rows=0` 时读到尺寸 ⇒ 偶发"什么都没画就退出"。
2. **就绪信号不能用占位文案**: Ink 给占位首字插了反白光标码, `输入消息` 在**字节里不连续**
   (`\x1b[7m输\x1b[27m\x1b[90m入消息`) ⇒ 改用 `Esc 双击退出`。
3. **还要等"加载中"那行消失**: `正在加载技能 / 工具...` 还在时打字会被吞 (真踩过: 11.9s 喂进去的按键, 输入框还是空的) ⇒
   就绪判据 = 在**最后一帧**里 "有快捷键提示" 且 "没有加载行" (全量匹配会把已经换掉的行算成"还在屏上")。
4. **`after` = 相对上一个事件真喂出去的时刻**: 第一个按键等画面, 后面按固定间隔一个接一个
   (全用绝对 `at` 会在就绪那一刻挤成一堆, 打进行缓冲 ⇒ 屏上只剩回显 `/c`)。
5. **每场景一个干净 HOME**: 共享 HOME 时前一个场景写进去的 setup 状态会改掉后一个场景的世界
   (同一份代码两条 preamble 一条 `credential_pending` 一条 `identity_pending`) ⇒ "老路径 vs verbose" 会假红。
6. **原地重绘不能拿"状态行"当帧界**: 选择器是光标上移 + 擦除原地重画, 原始字节里两帧会黏在一行上 ⇒
   改用**头行**当界量帧高。
7. **空抓包 ≠ 断红**: 一整轮 0 字节说明"什么都没测到", 夹具**重跑一次并在报告里点名**(断言一个字没改)。

## 9. 刻意保留 / 未做 (逐条)

1. **转录区尾巴裁切**: 历史上限内、且**第一条**消息比可视窗口还高时 (启动面板那十几行就属这种),
   最新追加的那行会被窗口下沿裁掉 (本次取证靠把终端给到 40 行)。**没修** —— 修它要改
   "按条裁" 的窗口模型, 且在启动期会把用户点名要看的**启动面板框**挤出屏幕。
2. **系统级剪贴板未真点**: 门用 stub 收字节证"真调了外部队列" (`pbcopy`/`clip.exe` 路径本身没跑),
   自报字符数 == 实收字符数 保证不是"假装复制了"。
3. **会话内 `/model` 只走到第 1 步** (供应商): 后续 6 步 (凭证/模型/参数/作用域/测试/确认) 由
   `bolloon model` 那条路的既有门 (`verify-model-ux.ts`) 覆盖 —— 两边是**同一套选择器**。
4. **未验**: 面板内鼠标选择/框选行为 (终端实现相关, 只能保证"不用 alt-screen + 不频繁清屏"这两条前提)。
5. **A7 的"没发生就只验一半"**: 本机 IPFS 可用时 DID 发布**不会降级**, 那一轮 A7 就退化成
   "只验面板前 0 行"并在报告里写明 —— 这是**如实**, 不是放宽: 地面真值来自盘上日志 (与上不上屏无关),
   想靠"把降级静掉"蒙过去, A7 反而会红 (M6 已证)。
6. **M6 只手工验了一次, `--mutation` 整轮 6 条没连跑**: 收尾轮时间不够, 只跑了这一条的真红;
   M1–M5 的红是上一轮跑的 (同一批锚点未变)。
