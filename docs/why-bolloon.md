## 写给谁看的

如果你符合下面这张画像的至少 5 项,那你大概率就是 Bolloon 在找的人:

- **年龄**:16–30 岁,本科到博士在读,或刚进入研究/创作/工业的头几年
- **学科背景**:研究 / 漫剧(漫画·剧作·动画) / 物理学 / 数学 / 神经科学 / 脑科学 / 工业 / 商科
- **AI 熟练度**:懂 AI 智能体的基本原理,自己用过、改造过、或者写过 prompt 给自己提效
- **付费意愿**:已经为大模型订阅 / API / 工具付费过,而且会继续付
- **品味**:能看出什么是好的,什么是平庸的,什么是在假装深刻
- **判断力**:在信息过载的环境里,敢拍板、能扛后果
- **创新力**:不满足于把现成工具再包装一层,想做一些还没人做过的事
- **想象力**:能在没有地图的地方画出第一条路
- **协作意愿**:希望和"同温层"的人一起做点真正有难度的事,而不是各自单干

## 为什么需要 Bolloon

### 1. 你不缺 AI,你缺的是"判断力被记住"

今天的 LLM 用法大多是"问一个问题,得一个答案"。聊完即忘,下次又是陌生人。

但你做的研究 / 漫画 / 物理推导 / 商业决策,是**连续的**——你昨天在某个方向上的取舍,今天应该被尊重,而不该被 LLM 当成新对话从零开始。

Bolloon 的核心承诺是:**把你的判断力记录下来,蒸馏成结构化的判断,在合适的时机注入回你下一次对话**。不是把"答案"塞给你,而是把"你为什么会这样决定"接住。

### 2. 你不缺工具,你缺的是"对等协作"

ChatGPT、Claude、Gemini 都是工具,但工具**不会和你一起承担错误的后果**。

Bolloon 是 P2P 网络——你的 bolloon 实例和你的合作者的 bolloon 实例直接连,**没有中心服务器**,**不归任何公司管**。你的判断力不会被人拿去训练模型,也不会因为某家厂商改 API 突然失联。

### 3. 你不缺聪明,你缺的是"被同水平的人看见"

16–30 岁、研究 / 漫剧 / 物理 / 数学 / 神经 / 工业 / 商科、懂 AI、付费过、有品味——这个交集本来就很小。在大厂的算法推荐里,你大概率被淹没在"效率工具"用户群里。

Bolloon 的网络默认是**邀请制的对等网络**,加入的人多半和你一个量级。你发出来的一条判断,会被同样有判断力的人接住,而不是被点赞机器扫过去。

## Bolloon 在做的是什么

- **判断力协议**:把"我为什么这样决定"沉淀为可携带、可注入、可检索的结构
- **P2P 文档智能体网络**:每个人跑自己的实例,跨机器互联,无需注册账号
- **多智能体协作原语**:让 A 和 B 在做重要决定前,把双方的反方观点互相看见,再由 Harness 驱动自动化执行
- **本地优先**:你的判断力、文档、聊天,默认存在 `~/.bolloon/`,不上云

## Bolloon 的优势

### 对个人

- **判断力持续累积**:不是"chat 即忘",是"判断力资产"随时间复利
- **跨设备同步**:笔记本 / 台式机 / iPad 的 bolloon 自动互联,身份不丢
- **多 LLM 可换**:今天用 MiniMax,明天换 Claude,后天换本地模型,你的判断力资产不绑定厂商
- **隐私自管**:判断力存本机,API key 存本机,文档存本机,不被任何第三方拿到

### 对协作

- **P2P 直连**:没有中间商,没有"平台抽成",没有"突然封号"
- **异步合作**:你提了一个想法,对方 6 小时后看到,接住往下做,不需要同步会议
- **决策可追溯**:谁在哪个时间点说了什么、为什么,事后能查
- **多智能体 Harness**:协作过程可以由 8-Gate 状态机驱动,适合需要严肃流程的研究 / 工程任务

### 对领域

- **研究**:把"我为什么觉得这条线索值得追"留下来,而不是埋在 1000 条 Notion 笔记里
- **漫剧**:把世界观、人设、剧情走向的取舍沉淀,跨集、跨季不丢失
- **物理 / 数学**:把推导中的"非显然的取舍"显式化,可检索、可对比
- **神经 / 脑科学**:把假设→实验→结论的链路结构化,方便回溯
- **工业 / 商科**:把决策日志留在自己手里,不归公司管,跳槽也带得走

## 一句话总结

**Bolloon = 你 + 一台永远记得你判断力的本地 AI 助理 + 一个由对等节点组成的协作网络。**

如果你已经在为"判断力被记住"和"对等协作"这两件事困扰,Bolloon 就是为你做的。
