## 亮点

- **第一个「带同名 tag 且双源交叉校验一致」的版本** —— npm `latest` 与仓库 tag `v0.5.0` 指向同一版, 交叉校验首次拿到真实例 (`kind = agree` · `hasTag = true`); 此前这条判据恒为 `missing_record`。
- **Goal 长期执行飞轮接进真实执行路径**: M0 接线冻结 (唯一责任链 + 源码级门) → M1–M4 接线 → M5 长周期真跑验收。不是「只交独立模块也没接线」, 冻结门 `34/34` 钉住责任链。
- **`bolloon update` 双源**: stable (npm) 与 dev (GitHub master HEAD) 两套比较语义, **源不可达必拒, 不静默落回旧版**。

## 新增能力

- 新 CLI 子命令 `bolloon task group create|join|list|link|leave` —— 任务群自助建群 / 入群 / 列群 / 关联 / 退群。
- 新 CLI 子命令 `bolloon identity init|show` —— 非交互建身份 (此前只能走交互向导)。
- `bolloon update --channel stable|dev`: stable 比版本号, dev 比 git ref + commit sha (`<版本>+dev.<sha7>`); `--channel nonsense` **必拒**。
- 飞轮能力落地: 自适应节奏 (固定轮次降级为安全上限, 主节奏由进展决定) · 强制收尾接成所有终止路径的必经阶段 · 新要求可注入**正在运行**的 Goal · 阻塞监控与用户可见状态映射 · 用户可见态补第 6 类终态「已结束」。
- 手机端任务协作四能力 (入群 / 发公告 / 过程留痕 / 看飞轮进度), 与桌面同一套授权验签。

## 修复

- 界面把**已完成**的 Goal 显示成「执行中」; 到点唤醒后**有进展**的目标被挂成「等外部」。
- `/goals` 页内联脚本转义错误导致**整页不渲染** —— 真 DOM 抓到 (22 败/SyntaxError, grep 文本看不见), 补齐漏改的 `view()` 转义后 **34 过 / 0 败**。
- 注入的用户原话**逐字**进下一个 Run 指令; 收尾候选 `contentHash` 改用 `stableHash` (原硬编码 `null` 被第二道门拒收)。
- `task announce|trail|post` 补进子命令白名单 —— 此前被当成一句任务正文真跑。
- 群 store 跨进程可重开: 区块与 datastore 真落盘 (含跨进程验收与负控制)。
- P5 验收真挖出的四处缺口一并修掉: 唤醒不拉状态 / 长等待醒不过来 / 合同门空转 / 飞轮判 delegate 被技能门禁截住。

## 升级方法

```bash
npm i -g @bolloon/bolloon-agent@0.5.0      # 指定版本安装
npm i -g @bolloon/bolloon-agent            # 或直接装最新
bolloon update                             # 已装用户就地更新 (stable 通道)
bolloon update --channel dev               # 想跟仓库 master HEAD 走
```
