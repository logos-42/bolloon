# Bolloon Agent v0.5.3

## 亮点

> 这一版把 x402 **卖方那一侧**补成闭环：**本机签名交付**（私钥不出本机、服务器只持公钥）、**无托管直付 `direct`**（买方自己发 USDC 到 `payTo`，卖方端点只读链核验）、**订单标识**（付款与「买的是哪件」同一笔交易自证）三条一起落地并上机 `pay.bolloon.cn`；
> 同时把**链上交互索引**的口径修正（付款行并入统一索引、退款不算已结算），并新增**地址↔DID 绑定登记**。

## 新增能力

- **地址 ↔ DID 绑定登记**（`diap-address-binding/1`，`9aa3a1d`）：双侧签名声明 + 付款行短写智能体名（链下登记），让「这笔付款是谁付的」可自证而不是靠推断。
- **x402 卖方本机签名交付**（`a525a5d`）：签名在卖方本机完成，**私钥不出本机**，服务器只持公钥；接口冻结。
- **x402 无托管直付模式 `direct`**（`88c4731`）：买方自己把 USDC 发到 `payTo`，卖方端点只读链核验，**没有托管环节**；已上机 `pay.bolloon.cn`。
- **x402 订单标识：EIP-3009 nonce（约定 v1 标签 `BOL1`）**（`bb94def`）：付款与「买的是哪件」由同一笔交易自证，链上可对账。
- **卖方公开只读汇总**（`122c440`）：`GET /api/x402/seller/summary`（卖方本机台账 · 链下，每笔带 `tx_hash` + 块号），供外部按同一口径查看。
- **链上交互索引**（`8f29900`）：付款行并入统一索引；计数口径修正（**退款不计入已结算**）。

## 修复

- **容器里启动即 `ERR_MODULE_NOT_FOUND`**（`1d88f0c`）：`undici` 原先靠传递提升，`npm ci --omit=dev` 装不到 ⇒ 镜像启动失败。已声明为直接依赖。
- **Docker 镜像版本写死**（`d04ee5d`）：`compose` 不再写死镜像版本号，默认本地 tag，可用 `BOLLOON_IMAGE_TAG` 固定。
