# Bolloon Agent v0.5.2

## 亮点

> 这一版最值钱的变化: **上传给模型的前缀不再是"每轮都变"的** —— 系统提示词稳定段与动态段分离、动态区注入后回写调用方 history、工具 schema 规范化, 同一会话内跨轮的前缀逐字节稳定, 于是服务端前缀缓存才有命中机会; 另外补上 **Docker 部署**与 **Efficode 语言参考实现**。

## 新增能力

- **前缀 KV 命中链** (`src/llm/pi-ai.ts` · `src/agents/pi-sdk.ts`):
  - system 提示词按**稳定段 / 动态段**分离; 动态段(当前轮上下文)注入为独立的 CURRENT TURN 块, **并回写调用方 history**, 使下一轮重组时前缀逐字节一致;
  - 注入**幂等**(已有标记则不重复注入); **工具 schema 规范化**(按 name 排序 + 递归 key 排序), 跨轮 tools 段哈希稳定;
  - `cache_prompt` 按用途分流: 只有主对话带缓存标记, 子调用(social/health/p2p/cron/summarize/autoCompact 等)走**轻量前缀**且不带工具全集;
  - `initPiAI` 按指纹幂等, 不受时间窗影响; 新增 KV 命中诊断行与 `stream_options` 回传 usage。
  - ⚠️ 边界说清: 本地 llama.cpp 单 slot 语境下的 `cache_prompt`/`timings.cache_n` 与云端(如 DeepSeek)服务端自动前缀缓存**语义不同**; 我们能保证的是**上传前缀逐字节稳定**(离线可断言), 命中率由服务端给出(可读 `usage.prompt_cache_hit_tokens`)。
- **Docker 部署** (`Dockerfile` · `docker-compose.yml` · `.dockerignore` · `.env.example` · `docs/wiki/docker-deployment.md`): 多阶段构建 · 非 root 运行 · `HEALTHCHECK` · `PORT=54188`; `.env.example` 只留变量名与空值。README 增加部署一节。
- **Efficode 语言参考实现** (`src/efficode/`): 指令集与前缀表达式 · 包封装(2B 头 + DID 摘要段 + 指令段 + 数据块 + CRC32)· 可插拔压缩层(LZ77)· 文本/二进制双模式 · 协商与回落(`lang: natural|efficode`, 双方都声明才用, 否则明确回落自然语言, 未知语言不硬解)· 规范页 `docs/wiki/efficode.md` · 手机端 Skills 页新增条目。
  - 短消息开销**真算**: 20 字节载荷带身份段 = **111 字节包**(算式 `2+32+1+50+1+1+20+4`, 与实测一致)⇒ 净开销 91 字节, 开销/载荷 **4.55x**; 固定开销 12B→7.58x · 100B→0.91x · 4KB→1.02x。即**短消息不省、大消息才划算**, 这条已写进规范页。

## 修复

- **内部运行日志又漏回回复流**(真缺陷): 现象 = 回复流里出现「开始 ReAct 循环 / 运行已登记 / 目标对齐 / 处理完成, 共 …」等内部行; 原因 = 回复流卫生判据函数 `isInternalRunLog` 在仓库里恒返回 `false`(一次变异验证的残留被误提交)⇒ 内部行既不拦也不落盘。修后: 回复流门 **15 passed / 0 failed**, 且三条变异(判据恒 false / 日志行生成拿掉 / 发送点标记拿掉)**全部真判红**; 日志文件 `[运行]` 通道可逐串 grep 到原文。
